# Visuele mascottecanon

Deze map is gereserveerd voor door de eigenaar goedgekeurde visuele
referenties. Referentiebeelden zijn de visuele bron van waarheid, maar worden
nooit rechtstreeks door de applicatie gerenderd.

Beoogde officiële bestanden:

- `versado-character-canon.png` — visuele samenvatting van de hele familie;
- `novi-character-sheet.png` — Novi-modelsheet en vaste proporties;
- `family-character-sheet.png` — familieverhoudingen, zodra beschikbaar.

Ontbrekende beelden worden niet gegenereerd of door tijdelijke alternatieven
vervangen. De eigenaar levert en keurt ze aan. De tekstuele bron van waarheid
staat in `docs/VERSADO-CHARACTER-CANON.md`; de officiële Novi-poses in
`../static/novi/` zijn aanvullende concrete pose-referenties.
